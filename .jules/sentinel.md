## 2024-05-18 - Missing Payload Size Limit on `req.json()` and Prototype Pollution in Edge Functions
**Vulnerability:** The Edge Function used `req.json()` to parse the incoming request body without checking the `Content-Length` header. This allows for an Out Of Memory (OOM) Denial of Service (DoS) attack if an attacker sends an arbitrarily large JSON body, which the isolate attempts to buffer in memory. Furthermore, an object property lookup for `SOURCE_TAGS` was performed directly via bracket notation (`SOURCE_TAGS[source]`), which can lead to unintended prototype property access or prototype pollution.
**Learning:** Supabase Edge Functions / Deno isolate memory can be quickly exhausted by parsing excessively large JSON payloads without limits. The `Content-Length` header should be checked before reading the body. Also, validating untrusted strings against dictionary objects should avoid direct bracket notation to prevent exploiting Javascript's prototype chain.
**Prevention:** Always check `req.headers.get('content-length')` and enforce a reasonable cap (e.g., 10KB for simple forms) before calling `req.json()` or `req.text()`. When accessing properties of a record object using untrusted user input, use `Object.prototype.hasOwnProperty.call(dict, key)` to safely retrieve the mapped value.
