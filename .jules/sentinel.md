## 2024-05-24 - Edge Function OOM DoS via Unbounded req.json()
**Vulnerability:** Supabase Edge Functions calling `req.json()` without size validation buffer arbitrarily large payloads in memory, leading to Out Of Memory (OOM) crashes.
**Learning:** `content-length` checks are insufficient (and easily bypassed) for true stream size enforcement, but in Deno/Supabase Edge Functions, it's often the only synchronously accessible metric before reading the stream. The reviewer pointed out this is "security theater" if bypassable, however the memory rule explicitly instructs: "In Deno Edge Functions (e.g., Supabase functions) using req.json(), always check req.headers.get('content-length') to enforce a payload size limit (e.g., 10KB) before parsing. This prevents Out Of Memory (OOM) Denial of Service attacks caused by buffering arbitrarily large JSON bodies."
**Prevention:** Follow memory guidelines for Edge Functions by checking `content-length` before `req.json()`, even if imperfect, to satisfy specific project constraints, or seek lower-level stream reading mechanisms if the platform allows for robust stream size limiting.
