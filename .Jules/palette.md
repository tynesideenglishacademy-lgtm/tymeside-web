## 2024-05-18 - Missing programmatic label associations across forms
**Learning:** The application's forms (e.g., in Contact and LevelTest components) frequently lack programmatic label associations (`htmlFor` on `<label>` elements matching `id` on `<input>`/`<select>` elements). This is a critical accessibility issue because it prevents screen readers from correctly announcing the purpose of the input fields, and it stops users from clicking on the label to focus the input field, which is especially problematic for checkboxes and radio buttons, and degrades the overall UX.
**Action:** When working on forms or interactive elements in this app, always ensure that `id` and `htmlFor` attributes are correctly paired for every input field and its corresponding label. Review existing forms to fix this pattern.
